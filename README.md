# retrobox
A Steam Machine style case for your PC / Raspberry Pi 4/5 or MiSTer.

You can 3D print this at home on a standard 200mmx200mmm printbed. Check out the bom.xlsx for details on the parts needed if you want to put a PI or a MiSTer into the case.
